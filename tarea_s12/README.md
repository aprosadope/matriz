##  Objetivo del programa
Este programa permite gestionar la reserva de asientos en una sala de cine representada por una matriz de 3 filas y 4 columnas.  
Cada asiento se identifica con un valor numérico:
- `0` → asiento libre  
- `1` → asiento reservado  

El usuario selecciona la fila y la columna del asiento que desea reservar, y el sistema actualiza la matriz mostrando el estado completo de la sala en formato de tabla.
